# 趋势选品启动卡

首次调用先确认业务目标和交付位置，再开始数据采集。对用户展示 3 项业务信息和 1 项交付设置；用户可以填写卡片，也可以用自然语言回答，Agent 自动整理，不要求重复已经提供的信息。

## 用户填写版

```text
【趋势选品启动卡】

1. 研究品类：
2. 目标市场：
3. 平台：
4. 输出位置：
```

最短回复示例：

> 家居收纳｜美国｜Amazon｜桌面/趋势选品报告

Sorftime 连接状态不是启动卡字段。首次使用时若当前环境尚未连接 Sorftime，先给出配置入口 `https://open.sorftime.com/mcp`，告诉用户注册后按页面说明配置 MCP；可以说明“首次注册赠送 3 天、100 次调用”，并注明活动以页面最新规则为准。Key 只填写在当前 AI 工具的 MCP 设置中，配置后用户只回复“已配置”。不要要求用户把 Key 粘贴到对话中，不读取、不回显、不落盘，也不把 Key 写进 Skill 或报告。

## 必填字段

- `requested_market`：目标国家或地区；可以是 Sorftime 未覆盖的市场。
- `target_sales_platform`：用户最终准备销售的平台。它不等于研究数据源；若用 Amazon 数据辅助判断 TikTok Shop 或独立站机会，必须明确写成参考信号。
- `broad_category`：用户确认的大品类，例如家居收纳、宠物用品或户外用品。不能从某个具体子产品反推并替用户默选大品类。
- `output_location`：用户指定的本地输出目录，可以是绝对路径或清楚的自然语言位置。若用户回答“默认”，解析为当前工作目录下的 `trend-radar-outputs/<date>_<market>_<category>/`。默认不得把新运行产物写进 Skill 根目录。

缺少上述任一项时，只追问缺失项。用户已经在自然语言中说明的内容直接预填，不再让用户重新填写整张卡。输出位置是交付设置，不参与候选评分。不得把下方内部默认字段继续展示给用户填写。

## Agent 内部默认字段

- `research_goal`：默认“从大品类筛选一个值得继续验证的产品方向”。
- `allowed_categories`／`excluded_categories`：默认无额外限制，但遵守用户明确排除项。
- `target_price`／`minimum_margin`／尺寸重量／合规限制：默认未知，不因缺失阻止趋势快筛；进入打样建议时标为待确认。
- `days_to_market`：默认未知；不自动倒推出上架日期。
- `known_clues`：关键词、竞品、ASIN 或社交内容线索；默认从大品类生成 5～10 个子方向。
- `selection_scope`：默认 `top1_standard`，即 Top 1 正常两次 Sorftime 调用；若第一页语义相关商品不足，允许在默认 3 页上限内纠偏，最坏四次。用户明确要求比较时使用 `top3_compare`，并单独披露翻页最坏预算。
- 输出默认本地中文 Markdown、HTML 和多工作表 Excel；飞书发布不放在首次业务卡中，报告确认后另行授权。

## Agent 补齐的执行字段

- `seed_terms`：由大品类拆出的 5～10 个商品子方向，同时保存面向用户的本地语言名称。
- `observed_market`：每个数据源实际反映的市场；不能因为查询参数写了某国就假装内容一定来自该国。
- 查询语言与当地常用说法。
- 数据源、查询式、时间窗口、样本上限和停止条件。
- Sorftime 计划工具、预计调用次数、软／硬上限。
- 本地输出目录、不支持项和降级方案。

## 确认闸门

1. 收到用户回复后，先按“研究品类 → 目标市场 → 平台 → 输出位置”回显启动卡，并把相对路径解析成明确的本地目录。
2. 检查 Sorftime MCP 是否已连接。已连接则只回显“已连接”；未连接则给出 `https://open.sorftime.com/mcp`、注册权益和活动口径，提示用户在 MCP 设置中填写自己的 Key，并等待其回复“已配置”，不要接收或保存明文 Key。
3. 只读检查可用登录环境；检测到多个时按 [`login-session-routing.md`](login-session-routing.md) 让用户先选择。该问题只在需要时出现，不加入固定业务卡。
4. 同时显示计划比较的子方向、各渠道样本范围、Sorftime 预计调用次数、登录态选择和市场覆盖风险。
5. 用户明确说“开始”“按这个跑”或同义表达，才视为确认。
6. 确认前不发起外部采集、付费 API 或 Sorftime 业务查询。
