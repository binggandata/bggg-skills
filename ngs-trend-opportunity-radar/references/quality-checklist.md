# 交付质检

- 用户看到的启动卡只有 3 项业务信息（研究品类、目标市场、平台）和 1 项交付设置（输出位置）；没有追加售价、毛利等选填字段。
- 输出目录已回显并落入 `research_brief.json`；新运行没有默认写进 Skill 根目录。
- 内部任务记录另行保存实际覆盖、样本上限和调用预算，不混入用户填写卡。
- 用户已提供的信息已自动预填；没有要求用户重复填写整张卡。
- 检测到多个登录环境时已让用户选择；单一登录环境已回显；没有匿名先跑、静默切换或混用账号。
- `research_brief.json` 只保存非敏感登录环境标签与路由，不含 Cookie、Token、邮箱、手机号或 profile 绝对路径。
- 研究任务卡有用户确认的研究品类；报告首屏展示“研究品类 → Sorftime 子类目 → 全候选 → 用户选择 Top N”，没有把模型自行联想的方向冒充 Sorftime 返回，也没有直接从具体产品开场。
- 用异市场、异品类测试输入检查过报告；没有残留上一轮的国家、日期、商品词、样本量或趋势数字。
- Top 10 每项都有 `source_id`、URL、平台和采集时间；不足 10 项时如实交付。
- Sorftime 正式父节点、第一层子类目、用户确认分支和展开后的子节点均已落盘；没有用宽泛业务词的 `category_search_from_product_name` 代替类目树。
- 默认类目树预算为每研究品类 5 次；少于／超过 4 个展开分支均有用户选择记录，超出预算前已确认。
- 每个候选方向至少保留一个 `source_category_node_ids` 和去重后的 `child_category_node_ids`；展开得到的孙节点没有被静默膨胀成候选池。
- 每个候选方向已取得一次有效 `category_report` 或记录明确缺失原因；`sparse`、`semantic_mismatch` 或 `blocked` 时没有继续排名，也没有由模型补造候选方向。
- Google Trends、TikTok、Reddit 对每个有效方向都有状态；没有因早期排名跳过免费源。
- 漏斗表逐方向说明通过项、卡点、进入深验／观察／淘汰决定和理由；`blocked` 没有写成零需求。
- Top N 来自用户明确选择；选择前没有调用商品搜索或 Amazon 评论。
- A／B 级至少有两个独立免费源信号，并已进入 Top N 深验；A 级满足商业验证和 Amazon 痛点证据门槛。
- TikTok 视频与评论分开统计；同一父视频评论没有被当作独立市场样本。
- TikTok 数量按方向核对；每个有效方向达到 ≥10 个相关视频、≥5 个账号或明确标记实际状态。
- Reddit API、old Reddit 同源 JSON 与可见 DOM 路线均记录 `collection_mode`；403／challenge／非 JSON 没有写成零需求。
- Reddit 帖子和评论分开统计；只有 1 个父帖或最大父帖占比超过 40% 时已标为集中，未冒充普遍需求。
- Reddit 用于趋势平台计数时达到每方向 ≥10 篇独立相关帖；评论仅作补充证据并披露父帖集中度。
- Google Trends 相对指数没有写成销量。
- 趋势查询已抽查语义；`ambiguous`／`mismatch` 没有计入 A／B 的趋势平台数。
- 非美市场没有静默使用 Amazon US 评论代表当地用户。
- Sorftime 工具和字段来自当前 Schema；调用日志不含密钥。
- Sorftime 返回类目已做相关性标记；偏题类目没有被当作商业验证通过。
- 类目树、全候选市场报告和 Top N 商品池分别记账；Top N 深验前已展示新增最少／最坏调用数。
- 每个深验方向商品语义不足时最多自动查看 3 页，按 ASIN 去重并记录每页新增有效数；任一方向第 4 页前已再次确认。
- 预计或实际超过 5 次已有用户确认，且没有超出确认后的任务预算。
- 默认未调用 `product_detail`、`product_reviews`；全候选 `category_report` 是快筛前的市场规模必需调用。
- 代表 ASIN 已人工做语义相关性检查，偏题商品没有进入 Amazon 评论。
- Amazon 评论按方向、ASIN 和采集模式披露；每个深验方向至少有 100 条书面评论，正常目标为 3～10 个 ASIN、300～1000 条；`full` 分星样本没有被拿来计算真实好评率。
- 每个关键数字能回到落盘文件；每个关键结论能回到原文证据。
- `research_data.xlsx` 已生成且只有一个正式下载入口；10 个渠道工作表名称、行数、筛选和冻结表头均已校验。
- 快筛阶段的 TikTok 评论、Reddit 评论、Sorftime 商品和 Amazon 评论若尚未运行，工作表内有 `status=not_run` 和阶段原因，不是空白页。
- 内部渠道 CSV 与工作簿各表行数一致；关键 source_id 可在原始 JSONL 找到。
- HTML 快筛阶段有 4～6 张决策图，深验阶段有 4～5 张；图下写明来源、n 和口径，实际覆盖正文不超过一段。
- HTML 按 `report-template.md` 的 14 个 section id 顺序输出；首屏、证据、数据下载和继续咨询章节均存在。
- 代表 ASIN 有产品图、标题和完整关键指标；图片加载失败时明确显示占位，不伪造图片。
- SVG 右侧标签未裁切；长评论能在报告内展开看到完整原文。
- 报告末尾有 3～5 个可继续咨询方向，但没有自动开展额外研究。
- 风险、反证、失败和缺失字段未被隐藏。
- 本地报告已生成并校验；未经确认没有写飞书或发机器人消息。
