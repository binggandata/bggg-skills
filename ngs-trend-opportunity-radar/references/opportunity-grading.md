# A／B／C／D 分层

V1 使用透明门槛，不使用未经真实案例校准的 100 分权重。

## 四个判断层

1. 趋势：是否为持续增长或稳定需求，而非单日事件脉冲。
2. 痛点：是否有真实、重复、可解决的用户问题或场景。
3. 商业：是否存在需求、价格空间、新品空间和可承受竞争。
4. 风险：合规、物流、季节窗口、头部垄断和结构性反证。

趋势平台数只统计 Google Trends、TikTok、Reddit 中，平台名规范化后、`query_semantic_status=matched` 且具备 `source_id`、URL、采集时间的证据。TikTok 只有达到每方向 ≥10 个相关视频、≥5 个账号的快筛门槛后计入；Reddit 只有达到每方向 ≥10 篇独立相关帖后计入。三个免费源都必须实际运行；`blocked` 是缺失，不是反证，`empty` 只有在查询语义与覆盖均已复核后才算弱信号。

候选同时保留两个维度：`screening_decision` 表示免费快筛后的“进入深验／观察／淘汰”，`grade` 表示当前证据完整度。未被用户选入 Top N 的方向只能记为“仅完成免费快筛”，不得因为按设计没有 Sorftime 商品和 Amazon 评论而写成商业失败。

## 分层规则

| 等级 | 最低条件 | 含义 |
|---|---|---|
| A | 三个免费源均已运行；≥2 个免费源形成有效信号；已进入 Top N 深验；Sorftime 类目／商品有效；目标市场有 Amazon 买后证据；≥2 个独立痛点簇；无硬排除 | 优先推进 |
| B | 三个免费源均已运行；≥2 个免费源形成有效信号；已进入 Top N 深验；商业与买后问题基本成立，但仍有 1～2 个关键缺口或风险 | 值得关注 |
| C | 已完成免费快筛但未进入 Top N，或平台交叉、目标市场覆盖、商业／买后证据不足 | 观察或待补证 |
| D | 命中用户排除类目／硬风险，趋势被反证，痛点不可解决，或商业条件明显不成立 | 暂不进入 |

缺失证据不能按中间分处理。缺失项必须进入 `missing_evidence`，并说明补证动作。三个免费源的 `blocked`／`semantic_mismatch` 都不是趋势通过；`empty` 只在成功请求且语义正确时视为弱信号。报告必须把每个未进入 Top N 的 `screening_decision`、`elimination_reasons` 和卡点写出来。

`bggg-data-amazon` 的默认采集只代表 Amazon US。目标市场不是美国时，只有明确标记为当地市场的用户数据或当地可靠评论源才可满足 A 级 Amazon 条件；美国评论只能作为跨市场启发。

## 产品假设卡

每个进入 A／B 的假设包含：目标人群、使用场景、原始痛点、现有替代方案、产品方向、搜索词、为什么现在可能成立、最大反证、待验证问题、证据来源和置信度。

允许的方向：痛点解决、配套附件、产品改良、场景细分。只生成有证据支撑的方向，不为凑数量强制四类齐全。
