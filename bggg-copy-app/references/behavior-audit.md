# 效果级对比协议（比 UI 更重要的验收）

> 原则：**每个"功能"都要回答：操作后实际发生了什么？与原版一致吗？**

## 1. 通用记录格式

| 字段 | 内容 |
|---|---|
| 操作 | 入口→点击→输入→提交 |
| 操作前 | 页面/素材数/版本数/余额/通知数 |
| 操作后 | 新页面/新素材/版本数/时长/余额/通知 |
| 原版结果 | 同上（真机实测） |
| 复刻结果 | 同上 |
| 结论 | ✅一致 / 🟡部分 / ❌差异（记录原因与修复） |

## 2. 必测清单

### 生成类
- 数量：1 份 / 多份 → 素材卡数量、是否独立素材
- 编辑：图片/视频修改 → 新素材还是同素材新版本？原片是否保留？
- 延长：时长是否真的增加（如 8s→16s）？新版本还是覆盖？
- 失败：卡片 ⚠/文案、重试是否可用、是否重复扣费
- 取消：哪些状态可取消、取消后余额/卡片状态

### 状态类
- 加载/进度：进度是否推进、退出重进是否恢复
- 通知：哪些操作发通知、标题/文案/时间、是否去重
- 多版本：pager 交互（点击/滑动/循环）、右侧指示条
- 空态/首屏：无项目/无素材/搜索无结果

### 计费类
- 图片/视频单价、按秒/按分辨率、余额与 UI 是否一致
- 失败/取消是否退款

## 3. 典型案例（FlowClone）
1. 延长 8s：原版成片 16s（拖到末尾 0:15），复刻拼接后 16s；第二次修复"后 8 秒不可解码"（网关分段分辨率不同 → Media3 Transformer 重编码）。
2. 视频编辑：原版同素材版本 2/2、卡片角标"N 项"，原片保留；复刻一致，并加 toast 提示。
3. 多份生成：N 份 = N 张独立素材卡；复刻一致。
4. 通知：仅视频生成/编辑/延长发通知，标题=提示词全文；复刻一致。
5. 计费：图片 0 点、720p 3 点/秒、480p 1 点/秒；复刻曾把 480p 按 720p 扣费，修复后 ledger 对齐。

## 4. 验收门槛
- L3 必须：每个核心功能有一条"原版 vs 复刻"的效果证据（截图/录屏/日志/DB 数值）
- L4 必须：失败注入（断网/停服/取消/杀进程）各一条恢复证据
