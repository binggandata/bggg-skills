# 踩坑清单（来自 FlowClone 实战，按出现频率）

## A. 设备/采集
1. **坐标漂移**：键盘/状态栏/滚动会让旧坐标失效 → 每次操作前重新 dump，按文本点击。
2. **MIUI 助手/搜索误触**：点击落到系统悬浮窗 → 点击前 `mCurrentFocus` 校验；误触后 `keyevent 4` 退出。
3. **键盘遮挡**：输入后按钮位置变化 → 先收键盘再 dump；别连按两次返回（第二下会关页面）。
4. **中文输入**：`adb input text` 对中文不可靠 → 用英文或分段/剪贴板。
5. **屏幕熄灭/锁屏**：`svc power stayon true`、`KEYCODE_WAKEUP`。
6. **USB 调试未开**：`adb devices` 空 → 手机开发者选项打开 USB 调试并授权。

## B. UI 解析
7. **Compose 语义缺失**：卡片无 text/desc → 截图 + bounds + 邻接文本推断。
8. **列表/网格列数判断错**：不同屏宽不同 → 以截图 + dump bounds 双证。
9. **动态态截图**：动画/进度中间态 → 固定等待 + 多次采样。
10. **多语言/动态文案**：不要硬编码中文；以不变量（图标/位置/结构）为主。

## C. 生成/任务
11. **前台协程任务丢失**：退出/被杀即失败 → submit/jobId/poll/download + 持久化恢复。
12. **重复扣费**：失败重试重新提交 → 保留 jobId，续查原任务。
13. **上传 401**：token 过期但上传接口没刷新 → 所有接口统一 401 refresh 重试。
14. **202 当成功**：服务端缓存/异步返回 202，被当 2xx 保存成 JSON → 仅 200/201 成功，其余重试/报错。
15. **内容下载慢**：上游 outputs 4MB 需 2–4 分钟 → 服务端缓存 + 客户端长超时/重试；不要 120s 超时。
16. **Android API 兼容**：`InputStream.readNBytes` 在 Android 11 不存在 → 手写读头；`minSdk` 下注意 API 级别。
17. **媒体类型校验过窄**：只认 MP4 头会误判图片（JPEG/PNG） → 按 magic bytes 全类型校验。
18. **媒体拼接分辨率不同**：见下条。

## D. 视频/媒体
19. **MediaMuxer 跨分辨率拼接**：第二段花屏/黑屏 → 统一缩放重编码（Media3 Transformer）。
20. **时长显示**：拼接后要用实际文件时长更新 UI，不能只信任原字段。
21. **编码参数**：音频采样率/声道、视频 profile/level 尽量统一；不统一时走转码。
22. **播放器错误**：`ExoPlayer` 的 `UnrecognizedInputFormat` 多半是文件不是有效媒体 → 检查下载内容。

## E. 计费/规则
23. **参数映射错**：显示 480p 但提交 quality=720p → 多扣费；端到端核对参数。
24. **图片也通知**：原版只对视频通知 → 规则要实测，不要按直觉。
25. **点数不足无提示**：生成前预检 + 服务端 402 友好文案。

## F. 工程/发布
26. **debug/release 签名冲突**：切换安装前卸载；发布包用正式 keystore（妥善备份）。
27. **密钥进 APK**：网关 Key 只放服务端；APK 内 properties key 留空。
28. **开源前脱敏**：删 DB/keystore/.bak/真实邮箱/密码/网关 IP；`grep` 复查。
29. **本地数据不按账号隔离**：切换账号后历史仍可见；商业版要按用户隔离。
30. **外部服务不稳定**：失败要有降级/重试/明确提示；别假装功能正常。
